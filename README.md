# 📘 Blockchain & Crypto Fundamentals — Educational Project
Built with Unity3D (v2021.3.f1)

This project is part of my ongoing personal initiative to make blockchain and cryptocurrency concepts accessible to newcomers. I'm passionate about both emerging technologies and education, and this application is my way of combining the two.

The goal of this repository is to demonstrate my approach to learning, problem-solving, and software development — from idea to execution. It reflects how I structure and build real-world educational tools, while continuously deepening my understanding of complex topics.
